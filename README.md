# astrbot_plugin_swissgear

在 LLM 回复发送前清理多余换行与全/半角括号包裹的动作描述的 [AstrBot](https://github.com/AstrBotDevs/AstrBot) 插件。

## 背景

使用 DeepSeek 等指令遵循较弱的模型时，即便在人设里明确要求「不要输出动作/神态描述」，模型仍会时不时冒出 `（微笑着看向你）` 这类内容，并夹带大量空行。本插件在回复真正发送前做一次自动清理，让输出更干净。

## 功能

- **删除括号动作描述**：按配置的括号对，删除括号及其包裹的内容，支持跨行匹配。默认处理全角 `（）` 和半角 `()`。
- **压缩多余换行**：去除行尾空白、清理连续空格，并把超出上限的连续换行压缩到设定值，同时去除首尾空白。
- **纯净无副作用**：仅在 `on_llm_response` 阶段处理文本，单条消息处理失败不会影响整体流程。

## 安装

将本插件目录放入 AstrBot 的插件目录（通常为 `data/plugins/`），或通过 AstrBot 面板的插件市场 / Git 仓库地址安装，然后重载插件即可。

## 配置

在 AstrBot 面板的插件配置页可调整以下项：

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `filter_brackets` | list | `["（）", "()"]` | 需要过滤的括号类型。每项须为两个字符（前为左括号，后为右括号），如 `（）`、`()`、`【】`、`[]`、`「」`。将删除这对括号及其包裹的内容（支持跨行）。 |
| `collapse_blank_lines` | bool | `true` | 是否压缩多余空行/换行。去除行尾空白并将连续多个换行压缩，同时清理首尾空白。 |
| `max_consecutive_newlines` | int | `1` | 允许的最大连续换行数。超过该数量的连续换行会被压缩到此值，`1` 表示不允许出现空行。 |

> 提示：涉及编程 / 数学场景时，建议从 `filter_brackets` 中移除半角 `()`，以免误删代码或公式。

## 示例

清理前：

```
你好呀 （微笑着看向你）


今天想聊点什么？ (歪头)
```

清理后（默认配置）：

```
你好呀
今天想聊点什么？
```

## 工作原理

插件监听 `@filter.on_llm_response()`，在 LLM 响应被组装成消息前拦截 `completion_text`：

1. 按 `filter_brackets` 逐类删除括号包裹的内容，使用负向字符集实现非贪婪、不跨越同类括号的跨行匹配。
2. 若开启 `collapse_blank_lines`，去除行尾空白、合并残留连续空格，并把超限的连续换行压缩到 `max_consecutive_newlines`，最后去除首尾空白。

非法的括号配置项（长度不为 2、左右字符相同）会被跳过并记录警告。
